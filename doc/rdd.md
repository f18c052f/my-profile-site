# プロフィールサイト 要件定義書 (v1.1)

## 1. 概要

本ドキュメントは、プロフィールサイトの要件定義書です。本サイトは、Y.Ohara の経歴、スキル、実績などを紹介し、友人・知人への情報共有、および転職活動を支援することを目的とします。

## 2. 開発方針

- **保守性・更新性の重視:** スキル情報など、定期的な更新が必要なコンテンツは、デプロイ不要または最小限の手順で更新できる仕組みを構築します。
- **段階的な機能拡張:** 将来的な機能追加を考慮し、拡張性の高い設計を行います。
- **Firebase の無料枠活用:** コストを最小限に抑えるため、Firebase の無料枠を最大限に活用します。無料枠を超える場合は、サイトを一時停止する運用とします。

## 3. ターゲットユーザー

- **主要ターゲット:** 友人・知人
- **特定ユーザー:** 転職先候補企業の人事担当者、転職エージェント (パスワード認証により詳細情報を閲覧可能)

## 4. サイト構成

- **トップページ:**
  - 自己紹介 (アイコン：自身の写真、簡単なプロフィール)
- **プロフィール:**
  - 学歴
  - 職務経歴 (特定ユーザーのみ詳細表示)
  - スキル (言語、フレームワーク、資格など)
  - 実績 (特許、論文、その他)
- **ギャラリー:**
  - 写真 (10 枚程度、趣味の写真など)
- **(オプション)動画:**
  - Firebase の無料枠で動画の埋め込みが難しい場合、このページは削除
  - YouTube 等の別サイトに掲載して、そこへのリンクをプロフィールサイトに貼ることは可能
- **共通レイアウト:**
  - ヘッダー (サイトタイトル、ナビゲーションメニュー)
  - フッター (コピーライト表記)
  - 言語切り替え (日本語/英語、自身で翻訳)
  - ダークモード切り替え
  - Google Analytics 設定

## 5. 機能要件

- **ユーザー認証:**
  - パスワード認証による特定ユーザーのログイン機能
- **コンテンツ管理:**
  - スキル、実績などの情報は、Firebase のデータベース(Firestore)で管理。
    - GUI での編集は希望だが、必須ではない。
    - コード(JSON)を編集し、デプロイなしで更新できる方法を優先。JSON 形式は指定なし。
- **レスポンシブデザイン:**
  - PC、スマートフォンでレイアウトが崩れないように対応
- **多言語対応:**
  - 日本語と英語のコンテンツ切り替え
- **ダークモード対応:**
  - ユーザーが任意でダークモード/ライトモードを切り替え可能
- **アクセス解析:**
  - Google Analytics によるアクセス状況の計測

## 6. 技術要件

- **フロントエンド:** Next.js
- **バックエンド:** Python (ロジックが必要な場合に使用)
- **インフラ:** Firebase (Hosting、Firestore、Authentication)
- **デザインライブラリ:**
  - shadcn/ui または Material UI
  - framer-motion (動きのある表現が必要な場合)

## 7. デザイン

- **全体的な雰囲気:** スタイリッシュ、モダン、おしゃれ
- **配色、フォント:** 詳細未定 (提案を希望)
- **背景:** 趣味の写真を背景に使用することを検討

## 8. コンテンツ更新

- **更新頻度:** 半年に 1 回程度
- **更新者:** ご自身
- **更新方法:**
  - Firestore のデータを直接編集 (JSON 形式)
  - Firebase コンソールから手動でデータを更新

## 9. 運用

- **公開範囲:** 全世界に公開
- **予算:** Firebase の無料枠内 (超える場合はサイト停止)
- **納期:** 特になし
