## 画面設計書 (v1.0)

### 全体構成

- **シングルページアプリケーション (SPA):** 1 つのページ内でコンテンツをスクロール表示します。
- **ページ内アンカーリンク:** ヘッダーのナビゲーションメニューから、ページ内の各セクションへスクロールします。

### 共通レイアウト

- **ヘッダー:**
  - 左: サイトタイトル (ロゴ)
  - 中央: ナビゲーションメニュー (アンカーリンク)
    - プロフィール
    - ギャラリー
  - 右:
    - 言語切り替え (トグルボタン: 日本語/English)
    - ダークモード切り替え (トグルボタン: ライト/ダーク)
- **フッター:**
  - コピーライト表記

### トップ (ヒーローセクション)

- 背景: 趣味の写真 (複数枚をスライドショー形式で表示)
- コンテンツ:
  - アイコン (自身の写真)
  - 名前 (キャッチフレーズ)
  - 簡単な自己紹介文

### プロフィールセクション

1.  **認証前 (デフォルト表示):**

    - 見出し: "Profile"
    - 学歴: タイムライン形式 (左に年、右に内容)
    - 職務経歴: タイムライン形式 (左に年、右に内容) - 概要のみ
    - スキル:
      - カテゴリ分け (例: "Programming Languages", "Frameworks/Libraries", "Tools", "Qualifications")
      - 各カテゴリ内にスキル名をリスト表示 (アイコン + スキル名)
    - 実績:
      - カテゴリ分け (例: "Patents", "Publications", "Awards")
      - 各カテゴリ内に実績名をリスト表示 (アイコン + 実績名)
    - パスワード入力フォーム:
      - ラベル: "Enter password to view more details:"
      - 入力欄: パスワード入力
      - ボタン: "Submit" (または "Unlock")

2.  **認証後 (パスワード認証成功):**

    - 職務経歴: 詳細を表示 (プロジェクト名、担当業務、使用技術など)
    - その他: 認証前と同じ

### ギャラリーセクション

- 見出し: "Gallery"
- 写真:
  - グリッドレイアウト (例: 3 列 x 3 行) で表示
  - 各画像にホバーエフェクト (例: 拡大、暗転)
- 動画:
  - 自動再生、ループ再生
  - コントロールバー非表示 (オプション: ホバー時に表示)
  - (注: Firebase の無料枠で対応できない場合は、YouTube 埋め込み等に変更)

## UI ライブラリ選定

今回の要件からすると`shadcn/ui`が適していると思われます。

- **スタイリッシュなデザイン:** 要件にある「スタイリッシュ、モダン、おしゃれ」な雰囲気に合致する。
- **カスタマイズ性:** 背景に写真を使うなど、デザインのカスタマイズが容易。
- **アクセシビリティ:** キーボード操作やスクリーンリーダーに対応しており、WAI-ARIA 属性も適切に設定されている。
- **コンポーネント:**
  - `Timeline` (タイムライン形式の表示)
  - `Accordion` (詳細情報の開閉)
  - `Dialog` (モーダル表示)
  - `Carousel` (スライドショー、ギャラリー)
- **framer-motion との連携:** `shadcn/ui`は`framer-motion`との相性が良く、スムーズなアニメーションやトランジションを実装できる。
