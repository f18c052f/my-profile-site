# 画面設計書 (v2.0)

v1.0 からの主な変更は、パスワード認証と職務経歴の詳細表示の廃止、ヒーローのスライドショー取りやめ、動画ページの削除、ギャラリーへのライトボックス追加です。

## 全体構成

- シングルページ。ヘッダーのアンカーリンクで `#profile` / `#gallery` へスクロールします
- ルーターは持ちません
- 固定ヘッダーに見出しが潜らないよう、`html` に `scroll-padding-top: 4rem` を指定しています

## 共通レイアウト

### ヘッダー（固定・半透明）

| 位置 | 内容                                                                                |
| ---- | ----------------------------------------------------------------------------------- |
| 左   | サイトタイトル（トップへ戻るリンク。`h1` ではない）                                 |
| 中央 | ナビゲーション（プロフィール / ギャラリー）。モバイルではハンバーガーメニューに収納 |
| 右   | 言語切り替え、テーマ切り替え、（モバイルのみ）メニュー開閉                          |

アイコンだけのボタンには `aria-label` を付けています。メニューの開閉ボタンは `aria-expanded` と `aria-controls` を持ちます。

### フッター

著作権表記のみ。年は実行時に算出します。

## 見出しの階層

`h1` はページ内に 1 つだけです。

```
h1  ヒーローのタイトル
h2  プロフィール / ギャラリー
h3  学歴 / 職務経歴 / スキル / 趣味 / 実績
h4  カードの見出し（会社名、スキルのカテゴリ名、特許/論文/登壇）
```

## トップ（ヒーロー）

- 高さ `100svh`（モバイルの URL バー伸縮による高さジャンプを避ける）
- 背景は写真を `<img>` で配置。`srcset` を効かせるため CSS の `background-image` は使いません
- 写真の上にグラデーションのスクリム（上下を締め、中央を相対的に明るく残す）を重ね、さらに本文ブロックの背後に半透明の下地と `backdrop-blur` を敷いてコントラストを確保します
- 丸いポートレート、タイトル、自己紹介文、GitHub / メールのリンク

## プロフィール

認証はありません。掲載しているのは公開可能な情報のみです。

| サブセクション | 形式                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| 学歴           | 左に年、右に内容の 2 列                                                 |
| 職務経歴       | カード。会社名・年・役職・概要のみ                                      |
| スキル         | カテゴリごとのカード。項目はアイコン + 名前のチップを折り返して並べます |
| 趣味           | カード。絵文字をタイトル行にインライン配置し、内容はタグで表示          |
| 実績           | 特許 / 論文 / 登壇の 3 カード。外部リンク付き                           |

## ギャラリー

- グリッド: モバイル 2 列（正方形）、`md` 以上 2 列、`lg` 以上 3 列（16:9）
- 各サムネイルは `<button>`。ホバーとフォーカスでタイトルを重ねて表示します
- クリックまたは Enter でライトボックスを開きます

### ライトボックス

ネイティブの `<dialog>` を `showModal()` で開きます。フォーカストラップ、Esc での閉じる、背景の不活性化、閉じたときの起動元へのフォーカス復帰はブラウザの実装に任せています。

| 操作     | 手段                              |
| -------- | --------------------------------- |
| 開く     | サムネイルのクリック / Enter      |
| 閉じる   | Esc、閉じるボタン、背景のクリック |
| 前後移動 | ← → キー、前後ボタン              |

表示中は背景のスクロールを止めます（`<dialog>` のモーダル表示だけでは止まらないため自前で行います）。前後の画像は先読みします。

## テーマ

- 初回訪問は OS の `prefers-color-scheme` に追従
- 以降は選択を `localStorage` に保存
- 初回描画の前に `index.html` のインラインスクリプトで `<html class="dark">` を確定させ、白い画面が一瞬出るのを防ぎます

## モーション

`MotionConfig reducedMotion="user"` により、OS の「動きを減らす」設定時はアニメーションを抑制します。スクロール連動のフェードインは共通の `revealProps` を使います。
